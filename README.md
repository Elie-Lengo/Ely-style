*Elystyle* est une boutique en ligne simple développée en HTML et Tailwind CSS. Ce projet est réalisé dans le cadre de ma formation en informatique à l'Université Protestante au Congo (UPC).

Pages du projet

- `index.html` : Page principale de la boutique
- `cart.html` : Page du panier
- `admin.html` : Interface d'administration
- `login.html` : Page de connexion

Technologies utilisées

- HTML5
- Tailwind CSS
- Supabase JS (en chargement pour fonctionnalités backend)
